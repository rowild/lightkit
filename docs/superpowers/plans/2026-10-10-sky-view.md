# Sky View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a full-screen 3D "sky view" to the solar page: a small planet with the selected place on top, the sun's path as a bow over it, and fans of golden and blue light from the place to the bow.

**Architecture:** Pure, tested geometry (`globeMath.ts`, `skyGeometry.ts`) turns `useSun()` data into points for two bow layouts. A Three.js scene in `app/utils/sky/` is loaded with `import()` only when the overlay opens; it holds a globe group (two planet looks) and a list of layers (bow, beads and sun, labels) that all glide between layouts through one morph mechanism. `SkyView.vue` owns the overlay, the explored place and the remembered choices.

**Tech Stack:** Nuxt 4, Vue 3.5, Three.js 0.186 (+ `three/addons`), GSAP 3.15 (already installed), SunCalc via `useSun`, Vitest 4 (node environment), Tailwind 4.

**Spec:** `docs/superpowers/specs/2026-10-10-sky-view-design.md` — read it before Task 1. Section numbers below refer to it.

```ts
/**
 * Where a place sits on the sky view's globe, and the turn that puts it on top.
 *
 * Plain arithmetic on tuples, no Three.js. `SkyView` needs these numbers before
 * the scene module has loaded, and Three.js has to stay out of the solar page's
 * first download. The conventions are section 4 of
 * docs/superpowers/specs/2026-10-10-sky-view-design.md.
 */

export type Vec3 = [number, number, number]
/** A unit quaternion as `[x, y, z, w]`, the order Three.js uses. */
export type Quat = [number, number, number, number]

const DEG = Math.PI / 180

/**
 * A place on the unit sphere, in the frame Three.js's default sphere UVs imply:
 * longitude 0 is +X, 90°E is −Z, 90°W is +Z and 180° is −X.
 */
export const latLngToModel = (lat: number, lng: number): Vec3 => {
  const phi = lat * DEG
  const lambda = lng * DEG
  return [Math.cos(phi) * Math.cos(lambda), Math.sin(phi), -Math.cos(phi) * Math.sin(lambda)]
}

/** Up, east and north at a place, in the globe's model frame. */
export const localFrame = (lat: number, lng: number): { up: Vec3; east: Vec3; north: Vec3 } => {
  const phi = lat * DEG
  const lambda = lng * DEG
  return {
    up: latLngToModel(lat, lng),
    east: [-Math.sin(lambda), 0, -Math.cos(lambda)],
    north: [-Math.sin(phi) * Math.cos(lambda), Math.cos(phi), Math.sin(phi) * Math.sin(lambda)]
  }
}

/**
 * A quaternion from a rotation matrix given by its rows. Shepperd's method,
 * the one `Quaternion.setFromRotationMatrix` uses, so the two agree.
 */
const quatFromRows = (r0: Vec3, r1: Vec3, r2: Vec3): Quat => {
  const [m00, m01, m02] = r0
  const [m10, m11, m12] = r1
  const [m20, m21, m22] = r2
  const trace = m00 + m11 + m22
  if (trace > 0) {
    const s = 0.5 / Math.sqrt(trace + 1)
    return [(m21 - m12) * s, (m02 - m20) * s, (m10 - m01) * s, 0.25 / s]
  }
  if (m00 > m11 && m00 > m22) {
    const s = 2 * Math.sqrt(1 + m00 - m11 - m22)
    return [0.25 * s, (m01 + m10) / s, (m02 + m20) / s, (m21 - m12) / s]
  }
  if (m11 > m22) {
    const s = 2 * Math.sqrt(1 + m11 - m00 - m22)
    return [(m01 + m10) / s, 0.25 * s, (m12 + m21) / s, (m02 - m20) / s]
  }
  const s = 2 * Math.sqrt(1 + m22 - m00 - m11)
  return [(m02 + m20) / s, (m12 + m21) / s, 0.25 * s, (m10 - m01) / s]
}

/**
 * The globe's rotation that carries a place to world +Y, its east to +X and
 * its north to −Z. The matrix's rows are east, up and south.
 */
export const orientationFor = (lat: number, lng: number): Quat => {
  const { up, east, north } = localFrame(lat, lng)
  const south: Vec3 = [-north[0], -north[1], -north[2]]
  return quatFromRows(east, up, south)
}

/** Rotate a vector by a unit quaternion. */
export const rotate = (q: Quat, v: Vec3): Vec3 => {
  const [qx, qy, qz, qw] = q
  const [x, y, z] = v
  const tx = 2 * (qy * z - qz * y)
  const ty = 2 * (qz * x - qx * z)
  const tz = 2 * (qx * y - qy * x)
  return [
    x + qw * tx + (qy * tz - qz * ty),
    y + qw * ty + (qz * tx - qx * tz),
    z + qw * tz + (qx * ty - qy * tx)
  ]
}

const conjugate = ([x, y, z, w]: Quat): Quat => [-x, -y, -z, w]

/**
 * The place under a world-space point on the globe, given the globe's current
 * rotation. Used when a tap lands on the planet.
 */
export const worldToLatLng = (point: Vec3, orientation: Quat): { lat: number; lng: number } => {
  const [x, y, z] = rotate(conjugate(orientation), point)
  const length = Math.hypot(x, y, z) || 1
  const lat = Math.asin(Math.min(1, Math.max(-1, y / length))) / DEG
  let lng = Math.atan2(-z, x) / DEG
  if (lng <= -180) lng += 360
  return { lat, lng }
}
```

```ts
/**
 * The sky view's day as plain data: the sun's path, the golden and blue
 * windows, the hour beads, and where each of them sits in the two bows.
 *
 * No Three.js and no browser API, so it is tested under node. It does no
 * astronomy of its own either: every altitude comes from `useSun`, and every
 * window from `getSolarSegments()`, so the sky view cannot disagree with the
 * Day Schedule bar (sky view spec, rule 2).
 */
import { useSun, SOLAR_ALTITUDES, type SolarSegment } from '../composables/useSun'
import type { Vec3 } from './globeMath'

export type BowMode = 'sky' | 'clock'
export type SkyKind = 'golden' | 'blue' | 'day' | 'twilight' | 'night'
export type WindowKind = 'golden' | 'blue' | 'day'

/** The fan slots, in time order. Each keeps a fixed place in the scene's buffers. */
export const WINDOW_NAMES = [
  'Morning Blue Hour',
  'Morning Golden Hour',
  'Daylight',
  'Evening Golden Hour',
  'Evening Blue Hour'
] as const
export type WindowName = (typeof WINDOW_NAMES)[number]

/** A fixed count, not a fixed step: two days always morph index by index. */
export const PATH_SAMPLES = 721
export const WINDOW_SAMPLES = 49
export const PLANET_RADIUS = 1
/** Bigger than the planet on purpose: the blue fans float clear of its curve (spec 5.7). */
export const BOW_RADIUS = 1.15
/** Where every fan starts: the selected place, on top of the planet. */
export const OBSERVER: Vec3 = [0, PLANET_RADIUS, 0]

export interface SkySample {
  /** Epoch milliseconds. */
  t: number
  /** Degrees above the horizon. */
  alt: number
  /** Compass degrees: 0 north, 90 east. */
  az: number
  /** Share of the span: 0 at the first nadir, 1 at the next. */
  f: number
  kind: SkyKind
}

export interface SkyWindow {
  name: WindowName
  kind: WindowKind
  start: Date
  end: Date
  /** WINDOW_SAMPLES samples from `start` to `end`, inclusive. */
  samples: SkySample[]
}

export interface SkyBead extends SkySample {
  /** `sin(alt)`, clamped: 0 below the horizon, 1 with the sun overhead. */
  strength: number
}

export interface SkyModel {
  lat: number
  lng: number
  /** South of the equator the camera and the clock bow face the other way. */
  southern: boolean
  spanStart: number
  spanEnd: number
  path: SkySample[]
  windows: SkyWindow[]
  beads: SkyBead[]
}

const DEG = Math.PI / 180
const HOUR = 3_600_000

const KIND_BY_SEGMENT: Record<string, SkyKind> = {
  'Morning Golden Hour': 'golden',
  'Evening Golden Hour': 'golden',
  'Morning Blue Hour': 'blue',
  'Evening Blue Hour': 'blue',
  'Daylight': 'day',
  'Civil Twilight Transition': 'twilight',
  'Night': 'night'
}

/** Only for a moment outside every segment. Inside one, the segment decides. */
const kindFromAltitude = (alt: number): SkyKind => {
  if (alt > SOLAR_ALTITUDES.goldenTop) return 'day'
  if (alt > SOLAR_ALTITUDES.horizon) return 'golden'
  if (alt > SOLAR_ALTITUDES.blueTop) return 'twilight'
  if (alt > SOLAR_ALTITUDES.blueBottom) return 'blue'
  return 'night'
}

const clamp01 = (x: number) => Math.min(1, Math.max(0, x))

export const buildSkyModel = (date: Date, lat: number, lng: number): SkyModel => {
  const sun = useSun()
  const segments = sun.getSolarSegments(date, lat, lng)

  // The Day Schedule's span: nadir to the next nadir. Should SunCalc give no
  // segments at all, a day centred on the date keeps the bow drawable.
  const spanStart = segments[0]?.start.getTime() ?? date.getTime() - 12 * HOUR
  const spanEnd = segments.at(-1)?.end.getTime() ?? date.getTime() + 12 * HOUR
  const span = spanEnd - spanStart

  const segmentAt = (t: number): SolarSegment | undefined =>
    segments.find(s => t >= s.start.getTime() && t < s.end.getTime()) ??
    (t === spanEnd ? segments.at(-1) : undefined)

  const sample = (t: number, kind?: SkyKind): SkySample => {
    const { altitude, azimuth } = sun.getSunPosition(new Date(t), lat, lng)
    const segment = segmentAt(t)
    return {
      t,
      alt: altitude,
      az: azimuth,
      f: (t - spanStart) / span,
      kind: kind ?? (segment && KIND_BY_SEGMENT[segment.name]) ?? kindFromAltitude(altitude)
    }
  }

  const path = Array.from({ length: PATH_SAMPLES }, (_, i) =>
    sample(spanStart + (span * i) / (PATH_SAMPLES - 1))
  )

  const windows: SkyWindow[] = []
  for (const segment of segments) {
    if (!(WINDOW_NAMES as readonly string[]).includes(segment.name)) continue
    const name = segment.name as WindowName
    const kind = KIND_BY_SEGMENT[name] as WindowKind
    const start = segment.start.getTime()
    const end = segment.end.getTime()
    windows.push({
      name,
      kind,
      start: segment.start,
      end: segment.end,
      // Every sample carries the window's own kind. The one at `end` belongs
      // to the next segment by the segment rule, and would otherwise tint the
      // fan's last edge in the wrong colour.
      samples: Array.from({ length: WINDOW_SAMPLES }, (_, i) =>
        sample(start + ((end - start) * i) / (WINDOW_SAMPLES - 1), kind)
      )
    })
  }

  // Full hours of the device clock. Stepping in real hours from the first one
  // keeps every bead on a full hour across a daylight-saving change.
  const beads: SkyBead[] = []
  const firstHour = new Date(spanStart)
  firstHour.setMinutes(0, 0, 0)
  let t = firstHour.getTime() < spanStart ? firstHour.getTime() + HOUR : firstHour.getTime()
  for (; t <= spanEnd; t += HOUR) {
    const s = sample(t)
    beads.push({ ...s, strength: clamp01(Math.sin(s.alt * DEG)) })
  }

  return { lat, lng, southern: lat < 0, spanStart, spanEnd, path, windows, beads }
}

/** When the sun is drawn: now on today's date, solar noon on any other. */
export const sunTimeFor = (date: Date, lat: number, lng: number, now: Date): Date => {
  const sameDay =
    date.getFullYear() === now.getFullYear() &&
    date.getMonth() === now.getMonth() &&
    date.getDate() === now.getDate()
  return sameDay ? now : useSun().getSolarTimes(date, lat, lng).solarNoon
}

/** The sun at a moment, as a sample of this model. `f` stays inside the span. */
export const sunSample = (model: SkyModel, time: Date): SkySample => {
  const { altitude, azimuth } = useSun().getSunPosition(time, model.lat, model.lng)
  const f = clamp01((time.getTime() - model.spanStart) / (model.spanEnd - model.spanStart))
  const nearest = model.path[Math.round(f * (PATH_SAMPLES - 1))]!
  return { t: time.getTime(), alt: altitude, az: azimuth, f, kind: nearest.kind }
}

/** A compass bearing and altitude as a direction in the world frame (spec 4.3). */
export const skyDirection = (az: number, alt: number): Vec3 => {
  const a = az * DEG
  const h = alt * DEG
  return [Math.cos(h) * Math.sin(a), Math.sin(h), -Math.cos(h) * Math.cos(a)]
}

/** The default camera's right-hand direction: −X seen from the north, +X from the south. */
export const viewerRight = (southern: boolean): Vec3 => (southern ? [1, 0, 0] : [-1, 0, 0])

/** Sky path: the sun where it really stands, on a sphere round the place. */
export const skyPoint = (s: { alt: number; az: number }, radius = BOW_RADIUS): Vec3 => {
  const [x, y, z] = skyDirection(s.az, s.alt)
  return [OBSERVER[0] + radius * x, OBSERVER[1] + radius * y, OBSERVER[2] + radius * z]
}

/** Clock: the span bent into a half circle, morning on the viewer's left. */
export const clockPoint = (f: number, southern: boolean, radius = BOW_RADIUS): Vec3 => {
  const theta = Math.PI * (1 - f)
  const [rx, , rz] = viewerRight(southern)
  return [
    OBSERVER[0] + radius * Math.cos(theta) * rx,
    OBSERVER[1] + radius * Math.sin(theta),
    OBSERVER[2] + radius * Math.cos(theta) * rz
  ]
}

export const layoutPoint = (s: SkySample, mode: BowMode, southern: boolean, radius = BOW_RADIUS): Vec3 =>
  mode === 'sky' ? skyPoint(s, radius) : clockPoint(s.f, southern, radius)

/**
 * How much of a sample stays visible: all of it on the clock; on the sky path,
 * fading from the horizon to nothing at −18°, where night is full. The night
 * half of the path dissolves instead of cutting through the planet.
 */
export const visibilityOnBow = (alt: number, mode: BowMode): number =>
  mode === 'clock' || alt >= 0 ? 1 : Math.max(0, 1 + alt / 18)
```

```ts
import { ref, getCurrentInstance, onUnmounted } from 'vue'

/**
 * Place search and place names from OpenStreetMap's Nominatim.
 *
 * Moved out of `LocationPicker.vue` on 2026-10-10 so the sky view could search
 * the same way. Same URLs, same 400ms debounce, same names as before.

/** One Nominatim search hit, as the API returns it. */
export interface PlaceResult {
  place_id: number
  display_name: string
  lat: string
  lon: string
}

type Fetcher = typeof fetch

const NOMINATIM = 'https://nominatim.openstreetmap.org'
const HEADERS = { 'Accept-Language': 'en' }
const DEBOUNCE_MS = 400

export const formatCoordinates = (lat: number, lng: number) =>
  `${lat.toFixed(4)}°, ${lng.toFixed(4)}°`

/**
 * Up to five places matching `query`. `null` when the request fails or is
 * refused, so a caller can keep what it was already showing.
 */
export const searchPlaces = async (query: string, fetcher: Fetcher = fetch): Promise<PlaceResult[] | null> => {
  try {
    const response = await fetcher(
      `${NOMINATIM}/search?format=json&limit=5&q=${encodeURIComponent(query)}`,
      { headers: HEADERS }
    )
    if (!response.ok) return null
    return (await response.json()) as PlaceResult[]
  } catch (err) {
    console.error('Error fetching geocoding results', err)
    return null
  }
}

/**
 * A short name for a coordinate: "City, Country" when the address has both,
 * else Nominatim's full display name, else the coordinates themselves. `null`
 * when the request fails or is refused.
 */
export const reverseGeocodeName = async (lat: number, lng: number, fetcher: Fetcher = fetch): Promise<string | null> => {
  try {
    const response = await fetcher(
      `${NOMINATIM}/reverse?format=json&lat=${lat}&lon=${lng}&zoom=12`,
      { headers: HEADERS }
    )
    if (!response.ok) return null
    const data = await response.json()
    const address = data?.address
    if (address) {
      const city = address.city || address.town || address.village || address.municipality || address.suburb
      if (city && address.country) return `${city}, ${address.country}`
    }
    if (data?.display_name) return data.display_name
    return formatCoordinates(lat, lng)
  } catch (err) {
    console.error('[usePlaceSearch] Reverse geocoding failed', err)
    return null
  }
}

/**
 * Wraps an async function so only the latest call's answer is delivered. An
 * answer that arrives after a newer call was made resolves to `undefined`: a
 * slow reply for the place tapped first must not overwrite the name of the
 * place tapped second.
 */
export const latestOnly = <A extends unknown[], R>(fn: (...args: A) => Promise<R>) => {
  let latest = 0
  return async (...args: A): Promise<R | undefined> => {
    const id = ++latest
    const result = await fn(...args)
    return id === latest ? result : undefined
  }
}

/**
 * A search field's state and its debounced lookup, shared by the map and the
 * sky view so the two behave the same way.
 */
export const usePlaceSearch = (fetcher: Fetcher = fetch) => {
  const query = ref('')
  const results = ref<PlaceResult[]>([])
  const showResults = ref(false)
  const search = latestOnly((q: string) => searchPlaces(q, fetcher))
  let timer: ReturnType<typeof setTimeout> | null = null

  const cancel = () => {
    if (timer) clearTimeout(timer)
    timer = null
  }

  const onInput = () => {
    cancel()
    if (!query.value.trim()) {
      results.value = []
      showResults.value = false
      return
    }
    // Debounced to be polite to Nominatim, whose usage policy asks for it.
    timer = setTimeout(async () => {
      const found = await search(query.value)
      if (!found) return
      results.value = found
      showResults.value = found.length > 0
    }, DEBOUNCE_MS)
  }

  const clear = () => {
    cancel()
    query.value = ''
    results.value = []
    showResults.value = false
  }

  if (getCurrentInstance()) onUnmounted(cancel)

  return { query, results, showResults, onInput, clear }
}
```

```js
// Rasterises Natural Earth land polygons into an equirectangular SVG, which
// ImageMagick then turns into public/textures/land-mask.png for the sky view's
// dot globe. Usage: node scripts/build-land-mask.mjs <land.geojson> <out.svg>
import { readFileSync, writeFileSync } from 'node:fs'

const [, , input, output] = process.argv
if (!input || !output) {
  console.error('Usage: node scripts/build-land-mask.mjs <land.geojson> <out.svg>')
  process.exit(1)
}

const WIDTH = 1024
const HEIGHT = 512
const project = ([lng, lat]) =>
  `${(((lng + 180) / 360) * WIDTH).toFixed(2)},${(((90 - lat) / 180) * HEIGHT).toFixed(2)}`

const geo = JSON.parse(readFileSync(input, 'utf8'))
const rings = []
for (const feature of geo.features) {
  const { type, coordinates } = feature.geometry
  const polygons = type === 'Polygon' ? [coordinates] : type === 'MultiPolygon' ? coordinates : []
  for (const polygon of polygons) {
    for (const ring of polygon) rings.push(`M${ring.map(project).join('L')}Z`)
  }
}

writeFileSync(
  output,
  `<svg xmlns="http://www.w3.org/2000/svg" width="${WIDTH}" height="${HEIGHT}" viewBox="0 0 ${WIDTH} ${HEIGHT}">` +
    `<rect width="${WIDTH}" height="${HEIGHT}" fill="#000"/>` +
    `<path fill="#fff" fill-rule="evenodd" d="${rings.join('')}"/></svg>`
)
console.log(`Wrote ${rings.length} rings to ${output}`)
```

```ts
  const first = SUN_STOPS[0]!
```

```ts
import type * as THREE from 'three'

/**
 * Free every geometry and material under `root`. Sprites keep their geometry:
 * Three.js shares one quad between all of them.
 */
export const disposeTree = (root: THREE.Object3D) => {
  root.traverse((object) => {
    const mesh = object as THREE.Mesh
    if (mesh.geometry && !(object as THREE.Sprite).isSprite) mesh.geometry.dispose()
    const material = mesh.material
    if (!material) return
    for (const m of Array.isArray(material) ? material : [material]) m.dispose()
  })
}
```

```ts
/** A sparse, slowly twinkling field of stars, far behind everything else (spec 7.8). */
import * as THREE from 'three'
import { PALETTE } from './palette'

const COUNT = 1500
const RADIUS = 50

export const createStars = (pixelRatio: number) => {
  const positions = new Float32Array(COUNT * 3)
  const sizes = new Float32Array(COUNT)
  const phases = new Float32Array(COUNT)
  for (let i = 0; i < COUNT; i++) {
    const u = Math.random() * 2 - 1
    const a = Math.random() * Math.PI * 2
    const r = Math.sqrt(1 - u * u)
    positions.set([RADIUS * r * Math.cos(a), RADIUS * u, RADIUS * r * Math.sin(a)], i * 3)
    sizes[i] = 0.5 + Math.random()
    phases[i] = Math.random() * Math.PI * 2
  }
  const geometry = new THREE.BufferGeometry()
  geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3))
  geometry.setAttribute('aSize', new THREE.BufferAttribute(sizes, 1))
  geometry.setAttribute('aPhase', new THREE.BufferAttribute(phases, 1))

  const material = new THREE.ShaderMaterial({
    uniforms: {
      uTime: { value: 0 },
      uPixelRatio: { value: pixelRatio },
      uColor: { value: new THREE.Color(PALETTE.star) }
    },
    vertexShader: /* glsl */ `
      attribute float aSize;
      attribute float aPhase;
      uniform float uTime;
      uniform float uPixelRatio;
      varying float vTwinkle;
      void main() {
        vTwinkle = 0.6 + 0.4 * sin(uTime * (0.5 + fract(aPhase) * 0.9) + aPhase);
        gl_PointSize = aSize * uPixelRatio * 1.6;
        gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
      }`,
    fragmentShader: /* glsl */ `
      uniform vec3 uColor;
      varying float vTwinkle;
      void main() {
        float d = length(gl_PointCoord - 0.5);
        gl_FragColor = vec4(uColor, smoothstep(0.5, 0.0, d) * vTwinkle);
        #include <colorspace_fragment>
      }`,
    transparent: true,
    depthWrite: false,
    blending: THREE.AdditiveBlending
  })

  const points = new THREE.Points(geometry, material)
  points.frustumCulled = false
  return {
    object: points,
    update: (time: number) => {
      material.uniforms.uTime!.value = time
    },
    dispose: () => {
      geometry.dispose()
      material.dispose()
    }
  }
}
```

```ts
/**
 * The sky view's Three.js scene. `SkyView.vue` loads this file with `import()`
 * when the overlay opens, so Three.js never enters the solar page's first
 * download (spec rule 4). It knows nothing about Vue.
 *
 * It holds the camera and its controls, the stars, the globe group that
 * carries the planet looks, and the layers drawn in the place's own frame.
 * Spec sections 7 and 8.
 */
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import { CSS2DRenderer } from 'three/addons/renderers/CSS2DRenderer.js'
import gsap from 'gsap'
import { worldToLatLng, type Quat } from '../globeMath'
import { PLANET_RADIUS, skyDirection, type BowMode, type SkyModel, type SkySample } from '../skyGeometry'
import { createStars } from './stars'
import type { Planet, SkyLayer } from './types'

export type PlanetMode = 'earth' | 'dots'
export type { BowMode }

export interface SkySceneOptions {
  canvas: HTMLCanvasElement
  /** An element laid exactly over the canvas, for the HTML labels. */
  labelLayer: HTMLElement
  reducedMotion: boolean
}

export interface SkyScene {
  setModel(model: SkyModel, orientation: Quat, opts: { animate: boolean }): void
  setBow(mode: BowMode, opts: { animate: boolean }): void
  /** Resolves once the look is showing; rejects when its images cannot load. */
  setPlanet(mode: PlanetMode, opts: { animate: boolean }): Promise<void>
  /** The sun for the current model, with that model's globe orientation. */
  setSun(sun: SkySample, orientation: Quat): void
  onPick(handler: (lat: number, lng: number) => void): void
  playIntro(): void
  resize(): void
  dispose(): void
}

type PlanetFactory = (renderer: THREE.WebGLRenderer) => Promise<Planet>

/** The planet looks this scene can build. A look not listed simply does not appear. */
const PLANET_FACTORIES: Partial<Record<PlanetMode, PlanetFactory>> = {}

const DEG = Math.PI / 180
const CAMERA_DISTANCE = 3.2
const CAMERA_ELEVATION = 22 * DEG
/** Half the width that must stay in view: the bow, its labels and a margin. */
const FIT_HALF_WIDTH = 1.6
const TAP_SLOP_PX = 6
const TAP_MAX_MS = 350
const MORPH_SECONDS = 1.2
const PLACE_SECONDS = 1.4
const PLANET_FADE_SECONDS = 0.6
const REDUCED_FADE_SECONDS = 0.2
const INTRO_SPIN = 25 * DEG

export const createSkyScene = ({ canvas, labelLayer, reducedMotion }: SkySceneOptions): SkyScene => {
  // Throws where WebGL is unavailable. SkyView catches it and shows its note.
  const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, powerPreference: 'high-performance' })
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  renderer.setClearColor(0x000000, 0)
  renderer.outputColorSpace = THREE.SRGBColorSpace

  const labels = new CSS2DRenderer({ element: labelLayer })
  const ctx = gsap.context(() => {})
  const animate = (make: () => void) => {
    ctx.add(make)
  }

  const scene = new THREE.Scene()
  const camera = new THREE.PerspectiveCamera(35, 1, 0.05, 200)
  const controls = new OrbitControls(camera, canvas)
  controls.enableDamping = true
  controls.enablePan = false
  controls.minPolarAngle = 0.15
  // Low enough to look up at the blue fans, never under the planet.
  controls.maxPolarAngle = Math.PI * 0.62

  const stars = createStars(renderer.getPixelRatio())
  scene.add(stars.object)

  // `spinner` carries the opening turn and rise; `globe` carries the place.
  const spinner = new THREE.Group()
  const globe = new THREE.Group()
  spinner.add(globe)
  scene.add(spinner)

  const layers: SkyLayer[] = []
  for (const layer of layers) scene.add(layer.object)

  const planets: Partial<Record<PlanetMode, Planet>> = {}
  const planetFade: Record<PlanetMode, { value: number }> = { earth: { value: 0 }, dots: { value: 0 } }
  const planetRise = { value: 1 }
  let planetRequest = 0

  // The sun is kept in the globe's own frame and turned into world space each
  // frame, so the day/night line rolls with the planet when the place changes.
  const sunInGlobe = new THREE.Vector3(0, 1, 0)
  const sunInWorld = new THREE.Vector3(0, 1, 0)
  const globeWorld = new THREE.Quaternion()

  let model: SkyModel | null = null
  let bowMode: BowMode = 'sky'
  let disposed = false
  let rollTween: gsap.core.Tween | null = null
  let swingTween: gsap.core.Tween | null = null
  let fadeTimeline: gsap.core.Timeline | null = null
  let intro: gsap.core.Timeline | null = null
  const layerFade = { value: 1 }

  // --- Camera -------------------------------------------------------------

  /** From the pole side, towards the equator: the bow leans away and both horizons show. */
  const cameraDirection = (southern: boolean) =>
    new THREE.Vector3(0, Math.sin(CAMERA_ELEVATION), (southern ? 1 : -1) * Math.cos(CAMERA_ELEVATION))

  /** Keep the bow's whole width in view; on an upright phone, pull back and centre the planet. */
  const fit = (direction = camera.position.clone().sub(controls.target).normalize()) => {
    const aspect = camera.aspect
    const target = new THREE.Vector3(0, aspect >= 1 ? PLANET_RADIUS + 0.35 : PLANET_RADIUS - 0.35, 0)
    const distance = Math.max(CAMERA_DISTANCE, FIT_HALF_WIDTH / (Math.tan((camera.fov * DEG) / 2) * aspect))
    controls.target.copy(target)
    controls.minDistance = Math.min(2.2, distance * 0.7)
    controls.maxDistance = Math.max(6, distance * 1.6)
    camera.position.copy(target).addScaledVector(direction, distance)
    controls.update()
  }

  /** Swing round to the other pole's side when the place crosses the equator. */
  const swingCamera = (southern: boolean, duration: number) => {
    swingTween?.kill()
    const spherical = new THREE.Spherical().setFromVector3(camera.position.clone().sub(controls.target))
    const goal = southern ? 0 : Math.PI
    const delta = Math.atan2(Math.sin(goal - spherical.theta), Math.cos(goal - spherical.theta))
    const place = (theta: number) => {
      spherical.theta = theta
      camera.position.copy(controls.target).add(new THREE.Vector3().setFromSpherical(spherical))
    }
    if (duration <= 0) {
      place(spherical.theta + delta)
      return
    }
    const swing = { theta: spherical.theta }
    animate(() => {
      swingTween = gsap.to(swing, {
        theta: spherical.theta + delta,
        duration,
        ease: 'power2.inOut',
        onUpdate: () => place(swing.theta)
      })
    })
  }

  // --- Picking ------------------------------------------------------------

  let pickHandler: ((lat: number, lng: number) => void) | null = null
  let press: { x: number; y: number; t: number } | null = null
  const raycaster = new THREE.Raycaster()
  const planetSphere = new THREE.Sphere(new THREE.Vector3(), PLANET_RADIUS)
  const pointer = new THREE.Vector2()

  const onPointerDown = (event: PointerEvent) => {
    // A second finger makes it a pinch, and a pinch is never a pick.
    press = event.isPrimary ? { x: event.clientX, y: event.clientY, t: performance.now() } : null
  }
  const onPointerUp = (event: PointerEvent) => {
    const start = press
    press = null
    if (!start || !pickHandler || !event.isPrimary) return
    // A drag turns the view; only a short, still press picks (spec 6.5).
    if (Math.hypot(event.clientX - start.x, event.clientY - start.y) > TAP_SLOP_PX) return
    if (performance.now() - start.t > TAP_MAX_MS) return
    const rect = canvas.getBoundingClientRect()
    pointer.set(((event.clientX - rect.left) / rect.width) * 2 - 1, -((event.clientY - rect.top) / rect.height) * 2 + 1)
    raycaster.setFromCamera(pointer, camera)
    const hit = raycaster.ray.intersectSphere(planetSphere, new THREE.Vector3())
    if (!hit) return
    globe.getWorldQuaternion(globeWorld)
    const { lat, lng } = worldToLatLng([hit.x, hit.y, hit.z], [globeWorld.x, globeWorld.y, globeWorld.z, globeWorld.w])
    pickHandler(lat, lng)
  }
  canvas.addEventListener('pointerdown', onPointerDown)
  canvas.addEventListener('pointerup', onPointerUp)

  // --- Loop ---------------------------------------------------------------

  let last = performance.now()
  let time = 0
  const frame = () => {
    const now = performance.now()
    // Frozen under reduced motion: shimmer, breathing and twinkle all stop.
    if (!reducedMotion) time += Math.min((now - last) / 1000, 0.1)
    last = now
    controls.update()
    globe.getWorldQuaternion(globeWorld)
    sunInWorld.copy(sunInGlobe).applyQuaternion(globeWorld)
    for (const mode of ['earth', 'dots'] as const) {
      const planet = planets[mode]
      if (!planet) continue
      const alpha = planetFade[mode].value * planetRise.value
      planet.object.visible = alpha > 0.001
      planet.setOpacity(alpha)
      planet.setSunDirection(sunInWorld)
      planet.update(time)
    }
    stars.update(time)
    for (const layer of layers) layer.update(time)
    renderer.render(scene, camera)
    labels.render(scene, camera)
  }
  const onVisibility = () => {
    last = performance.now()
    renderer.setAnimationLoop(document.hidden ? null : frame)
  }
  document.addEventListener('visibilitychange', onVisibility)
  renderer.setAnimationLoop(frame)

  // --- API ----------------------------------------------------------------

  const applyLayerFade = () => {
    for (const layer of layers) layer.setOpacity(layerFade.value)
  }
  /** Reduced motion: fade out, swap, fade in, instead of gliding. */
  const crossfade = (swap: () => void) => {
    fadeTimeline?.kill()
    animate(() => {
      fadeTimeline = gsap
        .timeline()
        .to(layerFade, { value: 0, duration: REDUCED_FADE_SECONDS / 2, onUpdate: applyLayerFade })
        .add(swap)
        .to(layerFade, { value: 1, duration: REDUCED_FADE_SECONDS / 2, onUpdate: applyLayerFade })
    })
  }

  const resize = () => {
    const width = canvas.clientWidth
    const height = canvas.clientHeight
    if (!width || !height) return
    renderer.setSize(width, height, false)
    labels.setSize(width, height)
    camera.aspect = width / height
    camera.updateProjectionMatrix()
    for (const layer of layers) layer.setResolution(width, height, renderer.getPixelRatio())
    fit()
  }

  const setModel: SkyScene['setModel'] = (next, orientation, { animate: animated }) => {
    const first = model === null
    const flipped = !first && model!.southern !== next.southern
    model = next
    const goal = new THREE.Quaternion(...orientation)
    if (first || !animated) {
      rollTween?.kill()
      globe.quaternion.copy(goal)
      for (const layer of layers) layer.setModel(next, 0)
      if (first) fit(cameraDirection(next.southern))
      else if (flipped) swingCamera(next.southern, 0)
      return
    }
    if (reducedMotion) {
      crossfade(() => {
        globe.quaternion.copy(goal)
        for (const layer of layers) layer.setModel(next, 0)
        if (flipped) swingCamera(next.southern, 0)
      })
      return
    }
    rollTween?.kill()
    const from = globe.quaternion.clone()
    const roll = { t: 0 }
    animate(() => {
      rollTween = gsap.to(roll, {
        t: 1,
        duration: PLACE_SECONDS,
        ease: 'power2.inOut',
        onUpdate: () => {
          globe.quaternion.slerpQuaternions(from, goal, roll.t)
        }
      })
    })
    for (const layer of layers) layer.setModel(next, PLACE_SECONDS)
    if (flipped) swingCamera(next.southern, PLACE_SECONDS)
  }

  const setBow: SkyScene['setBow'] = (mode, { animate: animated }) => {
    bowMode = mode
    if (animated && reducedMotion) {
      crossfade(() => {
        for (const layer of layers) layer.setMode(bowMode, 0)
      })
      return
    }
    for (const layer of layers) layer.setMode(mode, animated ? MORPH_SECONDS : 0)
  }

  const setSun: SkyScene['setSun'] = (sun, orientation) => {
    const inverse = new THREE.Quaternion(...orientation).invert()
    sunInGlobe.set(...skyDirection(sun.az, sun.alt)).applyQuaternion(inverse)
    for (const layer of layers) layer.setSun(sun)
  }

  const setPlanet: SkyScene['setPlanet'] = async (mode, { animate: animated }) => {
    const request = ++planetRequest
    if (!planets[mode]) {
      const factory = PLANET_FACTORIES[mode]
      if (!factory) return
      const built = await factory(renderer) // rejects when the images cannot load
      if (disposed || planets[mode]) {
        built.dispose()
        if (disposed) return
      } else {
        planets[mode] = built
        globe.add(built.object)
      }
    }
    if (request !== planetRequest) return // a newer choice won
    const duration = animated ? (reducedMotion ? REDUCED_FADE_SECONDS : PLANET_FADE_SECONDS) : 0
    for (const key of ['earth', 'dots'] as const) {
      const fade = planetFade[key]
      const goal = key === mode ? 1 : 0
      gsap.killTweensOf(fade)
      if (duration === 0) fade.value = goal
      else animate(() => gsap.to(fade, { value: goal, duration, ease: 'power1.inOut' }))
    }
  }

  const playIntro = () => {
    if (reducedMotion) return
    intro?.kill()
    spinner.rotation.y = INTRO_SPIN
    spinner.scale.setScalar(0.94)
    planetRise.value = 0
    animate(() => {
      intro = gsap.timeline()
      intro.to(spinner.rotation, { y: 0, duration: 1.2, ease: 'power3.out' }, 0)
      intro.to(spinner.scale, { x: 1, y: 1, z: 1, duration: 1.2, ease: 'power3.out' }, 0)
      intro.to(planetRise, { value: 1, duration: 1.0, ease: 'power1.out' }, 0)
      for (const layer of layers) layer.intro(intro)
    })
  }

  const dispose = () => {
    disposed = true
    renderer.setAnimationLoop(null)
    document.removeEventListener('visibilitychange', onVisibility)
    canvas.removeEventListener('pointerdown', onPointerDown)
    canvas.removeEventListener('pointerup', onPointerUp)
    ctx.kill()
    controls.dispose()
    stars.dispose()
    for (const planet of Object.values(planets)) planet?.dispose()
    for (const layer of layers) layer.dispose()
    labelLayer.replaceChildren()
    renderer.dispose()
    renderer.forceContextLoss()
  }

  camera.position.copy(cameraDirection(false)).multiplyScalar(CAMERA_DISTANCE)
  resize()

  return {
    setModel,
    setBow,
    setPlanet,
    setSun,
    onPick: (handler) => {
      pickHandler = handler
    },
    playIntro,
    resize,
    dispose
  }
}
```

```vue
 * planet, the sun's path as a bow over the selected place, and fans of light
 * from the place to the golden and blue parts of the bow.

  lat: number
  lng: number
  date: Date
}>()

const PLANET_OPTIONS = [

  { value: 'dots', label: 'Dots' }

  if (mode === 'earth') earthUnavailable.value = false

    : 'The sky view needs a connection the first time it opens.'

let resizeObserver: ResizeObserver | null = null

  resizeObserver?.disconnect()
  resizeObserver = null
  scene?.dispose()

const applyPlanet = async (animate: boolean) => {
  if (!scene) return
  try {
    await scene.setPlanet(planet.value, { animate })

    console.warn('[SkyView] Earth images unavailable, showing Dots', err)
    earthUnavailable.value = true
  }

const start = async () => {
  stop()
  const id = session
  status.value = 'loading'
  let sceneModule: typeof import('../../utils/sky/scene')
  try {
    sceneModule = await import('../../utils/sky/scene')
  } catch (err) {
    console.error('[SkyView] The scene could not load', err)
    if (id === session) status.value = 'needs-connection'
    return

  if (id !== session || !canvasEl.value || !labelEl.value) return

    scene = sceneModule.createSkyScene({
```

```ts
/**
 * The golden and blue bands, as both planet shaders draw them. The altitudes
 * come from `SOLAR_ALTITUDES`, so the bands on the planet are exactly the
 * phases the Day Schedule names (spec rule 2).
 */
import * as THREE from 'three'
import { SOLAR_ALTITUDES } from '../../composables/useSun'

const DEG = Math.PI / 180

/** The four boundaries as sines of altitude, the form the shaders compare. */
export const bandUniform = () =>
  new THREE.Vector4(
    Math.sin(SOLAR_ALTITUDES.goldenTop * DEG),
    Math.sin(SOLAR_ALTITUDES.horizon * DEG),
    Math.sin(SOLAR_ALTITUDES.blueTop * DEG),
    Math.sin(SOLAR_ALTITUDES.blueBottom * DEG)
  )

/** 1 inside [lo, hi], fading softly outside it. */
export const BAND_GLSL = /* glsl */ `
  float band(float x, float lo, float hi) {
    float soft = (hi - lo) * 0.45;
    return smoothstep(lo - soft, lo + soft * 0.3, x) * (1.0 - smoothstep(hi - soft * 0.3, hi + soft, x));
  }`
```

```ts
/**
 * The Earth look: NASA's Blue Marble by day, Black Marble city lights by
 * night, the golden and blue twilight bands, and a thin atmosphere (spec 7.3).
 */
import * as THREE from 'three'
import { BAND_GLSL, bandUniform } from './bands'
import { PALETTE } from './palette'
import type { Planet } from './types'

const loadTexture = async (loader: THREE.TextureLoader, url: string, renderer: THREE.WebGLRenderer) => {
  const texture = await loader.loadAsync(url)
  texture.colorSpace = THREE.SRGBColorSpace
  texture.anisotropy = Math.min(8, renderer.capabilities.getMaxAnisotropy())
  return texture
}

const WORLD_VERTEX = /* glsl */ `
  varying vec2 vUv;
  varying vec3 vNormalW;
  varying vec3 vPosW;
  void main() {
    vUv = uv;
    vNormalW = normalize(mat3(modelMatrix) * normal);
    vec4 world = modelMatrix * vec4(position, 1.0);
    vPosW = world.xyz;
    gl_Position = projectionMatrix * viewMatrix * world;
  }`

const SURFACE_FRAGMENT = /* glsl */ `
  uniform sampler2D uDay;
  uniform sampler2D uNight;
  uniform vec3 uSunDir;
  uniform vec3 uGolden;
  uniform vec3 uBlue;
  uniform vec3 uAir;
  uniform vec3 uDusk;
  uniform vec4 uBands;
  uniform float uOpacity;
  varying vec2 vUv;
  varying vec3 vNormalW;
  varying vec3 vPosW;
  ${BAND_GLSL}
  void main() {
    vec3 n = normalize(vNormalW);
    // The sine of the sun's altitude at this point of the planet.
    float s = dot(n, uSunDir);
    vec3 day = texture2D(uDay, vUv).rgb;
    vec3 night = texture2D(uNight, vUv).rgb;
    float light = smoothstep(-0.12, 0.10, s);
    vec3 lit = day * (0.2 + 1.05 * clamp(s * 1.4 + 0.15, 0.0, 1.0));
    float darkness = 1.0 - smoothstep(-0.2, 0.02, s);
    vec3 dark = day * 0.03 + night * vec3(1.0, 0.8, 0.55) * 1.5 * darkness;
    vec3 color = mix(dark, lit, light);
    color += uGolden * band(s, uBands.y, uBands.x) * 0.55;
    color += uBlue * band(s, uBands.w, uBands.z) * 0.5;
    // A thin bright limb on the lit side, warming along the day/night line.
    vec3 view = normalize(cameraPosition - vPosW);
    float rim = pow(1.0 - max(dot(n, view), 0.0), 3.0);
    float dusk = 1.0 - smoothstep(0.0, 0.3, abs(s));
    color += mix(uAir, uDusk, dusk) * rim * 0.45 * smoothstep(-0.25, 0.2, s);
    gl_FragColor = vec4(color, uOpacity);
    #include <tonemapping_fragment>
    #include <colorspace_fragment>
  }`

const AIR_FRAGMENT = /* glsl */ `
  uniform vec3 uSunDir;
  uniform vec3 uAir;
  uniform vec3 uDusk;
  uniform float uOpacity;
  varying vec3 vNormalW;
  varying vec3 vPosW;
  void main() {
    vec3 n = normalize(vNormalW);
    // Back faces point away from the camera: facing is 0 at the halo's outer
    // edge and grows towards the planet, which hides everything inside it.
    float facing = dot(n, normalize(vPosW - cameraPosition));
    float halo = pow(clamp(facing * 3.6, 0.0, 1.0), 1.6);
    float s = dot(n, uSunDir);
    float lit = smoothstep(-0.3, 0.25, s);
    float dusk = 1.0 - smoothstep(0.0, 0.32, abs(s + 0.04));
    vec3 color = mix(uAir, uDusk, dusk) * halo * (0.12 + 0.88 * lit) * uOpacity;
    gl_FragColor = vec4(color, 1.0);
    #include <colorspace_fragment>
  }`

export const createEarth = async (renderer: THREE.WebGLRenderer): Promise<Planet> => {
  const loader = new THREE.TextureLoader()
  const [day, night] = await Promise.all([
    loadTexture(loader, '/textures/earth-day.jpg', renderer),
    loadTexture(loader, '/textures/earth-night.jpg', renderer)
  ])
  const sun = new THREE.Vector3(0, 1, 0)
  const air = new THREE.Color(PALETTE.dayAir)
  const dusk = new THREE.Color(PALETTE.duskAir)

  const surfaceMaterial = new THREE.ShaderMaterial({
    uniforms: {
      uDay: { value: day },
      uNight: { value: night },
      uSunDir: { value: sun },
      uGolden: { value: new THREE.Color(PALETTE.golden) },
      uBlue: { value: new THREE.Color(PALETTE.blue) },
      uAir: { value: air },
      uDusk: { value: dusk },
      uBands: { value: bandUniform() },
      uOpacity: { value: 1 }
    },
    vertexShader: WORLD_VERTEX,
    fragmentShader: SURFACE_FRAGMENT,
    transparent: true
  })
  const surface = new THREE.Mesh(new THREE.SphereGeometry(1, 128, 64), surfaceMaterial)
  surface.renderOrder = 0

  const airMaterial = new THREE.ShaderMaterial({
    uniforms: {
      uSunDir: { value: sun },
      uAir: { value: air },
      uDusk: { value: dusk },
      uOpacity: { value: 1 }
    },
    vertexShader: WORLD_VERTEX,
    fragmentShader: AIR_FRAGMENT,
    side: THREE.BackSide,
    transparent: true,
    depthWrite: false,
    blending: THREE.AdditiveBlending
  })
  const atmosphere = new THREE.Mesh(new THREE.SphereGeometry(1.04, 96, 48), airMaterial)
  atmosphere.renderOrder = 1

  const group = new THREE.Group()
  group.add(surface, atmosphere)

  return {
    object: group,
    setSunDirection: (direction) => {
      sun.copy(direction)
    },
    setOpacity: (alpha) => {
      surfaceMaterial.uniforms.uOpacity!.value = alpha
      airMaterial.uniforms.uOpacity!.value = alpha
    },
    update: () => {},
    dispose: () => {
      surface.geometry.dispose()
      atmosphere.geometry.dispose()
      surfaceMaterial.dispose()
      airMaterial.dispose()
      day.dispose()
      night.dispose()
    }
  }
}
```

```ts
/**
 * The dot globe: land as a field of small dots in the app's petrol, lit by the
 * same sun, with the golden and blue bands lighting the dots they cross
 * (spec 7.4).
 */
import * as THREE from 'three'
import { BAND_GLSL, bandUniform } from './bands'
import { PALETTE } from './palette'
import type { Planet } from './types'

const CANDIDATES = 40_000
const DOT_RADIUS = 1.002
const RAD = 180 / Math.PI

/**
 * The land mask as a lookup. Without it - a first opening while offline -
 * every point counts as land, so the globe still appears, as a full sphere.
 */
const loadLandLookup = async (): Promise<(lat: number, lng: number) => boolean> => {
  try {
    const image = new Image()
    image.src = '/textures/land-mask.png'
    await image.decode()
    const canvas = document.createElement('canvas')
    canvas.width = image.naturalWidth
    canvas.height = image.naturalHeight
    const context = canvas.getContext('2d', { willReadFrequently: true })!
    context.drawImage(image, 0, 0)
    const { data, width, height } = context.getImageData(0, 0, canvas.width, canvas.height)
    return (lat, lng) => {
      const x = Math.min(width - 1, Math.floor(((lng + 180) / 360) * width))
      const y = Math.min(height - 1, Math.floor(((90 - lat) / 180) * height))
      return data[(y * width + x) * 4]! > 127
    }
  } catch {
    return () => true
  }
}

const DOT_VERTEX = /* glsl */ `
  uniform vec3 uSunDir;
  uniform float uSize;
  uniform float uPixelRatio;
  varying float vSin;
  void main() {
    vSin = dot(normalize(mat3(modelMatrix) * position), uSunDir);
    vec4 mv = modelViewMatrix * vec4(position, 1.0);
    gl_PointSize = uSize * uPixelRatio * clamp(3.2 / -mv.z, 0.45, 1.4);
    gl_Position = projectionMatrix * mv;
  }`

const DOT_FRAGMENT = /* glsl */ `
  uniform vec3 uDay;
  uniform vec3 uNight;
  uniform vec3 uGolden;
  uniform vec3 uBlue;
  uniform vec4 uBands;
  uniform float uOpacity;
  varying float vSin;
  ${BAND_GLSL}
  void main() {
    float d = length(gl_PointCoord - 0.5);
    if (d > 0.5) discard;
    float edge = smoothstep(0.5, 0.3, d);
    float light = smoothstep(-0.12, 0.1, vSin);
    vec3 color = mix(uNight, uDay * (0.75 + 0.7 * clamp(vSin, 0.0, 1.0)), light);
    color = mix(color, uGolden * 1.2, band(vSin, uBands.y, uBands.x));
    color = mix(color, uBlue * 1.15, band(vSin, uBands.w, uBands.z));
    gl_FragColor = vec4(color, edge * uOpacity);
    #include <colorspace_fragment>
  }`

export const createDots = async (renderer: THREE.WebGLRenderer): Promise<Planet> => {
  const isLand = await loadLandLookup()
  const positions: number[] = []
  const goldenAngle = Math.PI * (3 - Math.sqrt(5))
  for (let i = 0; i < CANDIDATES; i++) {
    const y = 1 - (2 * (i + 0.5)) / CANDIDATES
    const r = Math.sqrt(1 - y * y)
    const x = Math.cos(goldenAngle * i) * r
    const z = Math.sin(goldenAngle * i) * r
    // The globe's model frame (spec 4.1): latitude from y, longitude from x and −z.
    if (isLand(Math.asin(y) * RAD, Math.atan2(-z, x) * RAD)) {
      positions.push(x * DOT_RADIUS, y * DOT_RADIUS, z * DOT_RADIUS)
    }
  }
  const geometry = new THREE.BufferGeometry()
  geometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3))

  const sun = new THREE.Vector3(0, 1, 0)
  const material = new THREE.ShaderMaterial({
    uniforms: {
      uSunDir: { value: sun },
      uSize: { value: 4.5 },
      uPixelRatio: { value: renderer.getPixelRatio() },
      uDay: { value: new THREE.Color(PALETTE.dotsDay) },
      uNight: { value: new THREE.Color(PALETTE.dotsNight) },
      uGolden: { value: new THREE.Color(PALETTE.golden) },
      uBlue: { value: new THREE.Color(PALETTE.blue) },
      uBands: { value: bandUniform() },
      uOpacity: { value: 1 }
    },
    vertexShader: DOT_VERTEX,
    fragmentShader: DOT_FRAGMENT,
    transparent: true,
    depthWrite: false
  })
  const dots = new THREE.Points(geometry, material)
  dots.renderOrder = 1

  // A dark core hides the far side's dots.
  const coreMaterial = new THREE.MeshBasicMaterial({ color: PALETTE.dotsCore, transparent: true })
  const core = new THREE.Mesh(new THREE.SphereGeometry(0.995, 64, 32), coreMaterial)
  core.renderOrder = 0

  const group = new THREE.Group()
  group.add(core, dots)

  return {
    object: group,
    setSunDirection: (direction) => {
      sun.copy(direction)
    },
    setOpacity: (alpha) => {
      material.uniforms.uOpacity!.value = alpha
      coreMaterial.opacity = alpha
    },
    update: () => {},
    dispose: () => {
      geometry.dispose()
      material.dispose()
      core.geometry.dispose()
      coreMaterial.dispose()
    }
  }
}
```

```ts
/**
 * Morph buffers: typed arrays that glide from where they are to where they
 * should be. The bow, the beads, the sun and the labels all move this way, so
 * a bow switch, a new place and the live sun share one mechanism (spec 8).
 */
import gsap from 'gsap'

export class Morph {
  readonly current: Float32Array
  private readonly from: Float32Array
  private readonly to: Float32Array
  private moving = false

  constructor(length: number) {
    this.current = new Float32Array(length)
    this.from = new Float32Array(length)
    this.to = new Float32Array(length)
  }

  /** Aim at `target`, starting from wherever the values are now. */
  retarget(target: ArrayLike<number>) {
    this.from.set(this.current)
    this.to.set(target)
    this.moving = true
  }

  /** Move to `progress` (0–1) of the way. A morph with no target stays put. */
  apply(progress: number) {
    if (!this.moving) return
    const { current, from, to } = this
    for (let i = 0; i < current.length; i++) current[i] = from[i]! + (to[i]! - from[i]!) * progress
    if (progress >= 1) this.moving = false
  }
}

/**
 * Drives a set of morphs through one eased progress value. A new run starts
 * from wherever the values are, so a change in mid-glide never jumps back.
 */
export const createMorphRunner = (morphs: Morph[], onFrame: () => void) => {
  const state = { progress: 1 }
  let tween: gsap.core.Tween | null = null
  return {
    get running() {
      return tween !== null
    },
    /** Call after retargeting. A duration of 0 arrives at once. */
    run(duration: number, onDone?: () => void) {
      tween?.kill()
      tween = null
      if (duration <= 0) {
        for (const morph of morphs) morph.apply(1)
        onFrame()
        onDone?.()
        return
      }
      state.progress = 0
      tween = gsap.to(state, {
        progress: 1,
        duration,
        ease: 'power2.inOut',
        onUpdate: () => {
          for (const morph of morphs) morph.apply(state.progress)
          onFrame()
        },
        onComplete: () => {
          tween = null
          onDone?.()
        }
      })
    },
    kill() {
      tween?.kill()
      tween = null
    }
  }
}
```

```ts
 * The bow: the sun's path, the fans from the place to the golden and blue
 * windows with a bright rim along each, the horizon ring and the pin
 * (spec 5.7, 7.5 and 7.7).
 */
import * as THREE from 'three'
import { Line2 } from 'three/addons/lines/Line2.js'
import { LineGeometry } from 'three/addons/lines/LineGeometry.js'
import { LineMaterial } from 'three/addons/lines/LineMaterial.js'
import type gsap from 'gsap'
import {
  BOW_RADIUS,
  OBSERVER,
  PATH_SAMPLES,
  WINDOW_NAMES,
  WINDOW_SAMPLES,
  layoutPoint,
  visibilityOnBow,
  type BowMode,
  type SkyModel,
  type WindowName

import { Morph, createMorphRunner } from './morph'
import { KIND_COLORS, KIND_INTENSITY, PALETTE } from './palette'
import { glowTexture } from './textures'
import type { SkyLayer } from './types'

const R = BOW_RADIUS
const O = new THREE.Vector3(...OBSERVER)
const FAN_TRIANGLES = WINDOW_SAMPLES - 1

const FAN_STYLE: Record<WindowName, { color: string; strength: number }> = {
  'Morning Blue Hour': { color: PALETTE.blue, strength: 0.5 },
  'Morning Golden Hour': { color: PALETTE.golden, strength: 0.55 },
  'Daylight': { color: PALETTE.structure, strength: 0.11 },
  'Evening Golden Hour': { color: PALETTE.golden, strength: 0.55 },
  'Evening Blue Hour': { color: PALETTE.blue, strength: 0.5 }
}

const FAN_VERTEX = /* glsl */ `
  attribute float aEdge;
  attribute float aAlong;
  uniform vec3 uOrigin;
  uniform float uReveal;
  varying float vEdge;
  varying float vAlong;
  void main() {
    vEdge = aEdge;
    vAlong = aAlong;
    // The opening unfolds every fan out of the pin.
    vec3 p = uOrigin + (position - uOrigin) * uReveal;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(p, 1.0);
  }`

const FAN_FRAGMENT = /* glsl */ `
  uniform vec3 uColor;
  uniform float uStrength;
  uniform float uOpacity;
  uniform float uTime;
  varying float vEdge;
  varying float vAlong;
  void main() {
    // Soft at the pin, bright at the bow.
    float body = pow(vEdge, 1.5);
    // Feather the two straight edges a touch, so they read as light, not paper.
    float sides = smoothstep(0.0, 0.035, vAlong) * smoothstep(1.0, 0.965, vAlong);
    // A slow shimmer travelling along the fan, and faint rays across it.
    float shimmer = 0.86 + 0.14 * sin(vAlong * 22.0 - uTime * 1.1 + vEdge * 5.0);
    float rays = 0.82 + 0.18 * sin(vAlong * 140.0 + sin(uTime * 0.3) * 2.0);
    gl_FragColor = vec4(uColor, body * sides * shimmer * rays * uStrength * uOpacity);
    #include <colorspace_fragment>
  }`

const makeLine = (points: number, width: number, color: string | null) => {
  const geometry = new LineGeometry()
  geometry.setPositions(new Float32Array(points * 3))
  if (color === null) geometry.setColors(new Float32Array(points * 3))
  const material = new LineMaterial({
    linewidth: width,
    color: color ?? 0xffffff,
    vertexColors: color === null,
    transparent: true,
    depthWrite: false,
    blending: THREE.AdditiveBlending
  })
  const line = new Line2(geometry, material)
  line.frustumCulled = false
  return { line, geometry, material }
}

/**
 * Write points (and colours) into a fat line's existing buffers. `setPositions`
 * would allocate new ones on every frame of a glide.
 */
const writeLine = (geometry: LineGeometry, points: Float32Array, colors?: Float32Array) => {
  const write = (name: 'instanceStart' | 'instanceColorStart', source: Float32Array) => {
    const attribute = geometry.getAttribute(name) as THREE.InterleavedBufferAttribute
    const array = attribute.data.array as Float32Array
    const segments = source.length / 3 - 1
    for (let i = 0; i < segments; i++) {
      array[i * 6] = source[i * 3]!
      array[i * 6 + 1] = source[i * 3 + 1]!
      array[i * 6 + 2] = source[i * 3 + 2]!
      array[i * 6 + 3] = source[i * 3 + 3]!
      array[i * 6 + 4] = source[i * 3 + 4]!
      array[i * 6 + 5] = source[i * 3 + 5]!
    }
    attribute.data.needsUpdate = true
  }
  write('instanceStart', points)
  if (colors) write('instanceColorStart', colors)
}

const makeFan = (name: WindowName) => {
  const positions = new Float32Array(FAN_TRIANGLES * 9)
  const edge = new Float32Array(FAN_TRIANGLES * 3)
  const along = new Float32Array(FAN_TRIANGLES * 3)
  for (let i = 0; i < FAN_TRIANGLES; i++) {
    edge.set([0, 1, 1], i * 3)
    along.set([(i + 0.5) / FAN_TRIANGLES, i / FAN_TRIANGLES, (i + 1) / FAN_TRIANGLES], i * 3)
  }
  const geometry = new THREE.BufferGeometry()
  geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3).setUsage(THREE.DynamicDrawUsage))
  geometry.setAttribute('aEdge', new THREE.BufferAttribute(edge, 1))
  geometry.setAttribute('aAlong', new THREE.BufferAttribute(along, 1))
  const style = FAN_STYLE[name]
  const material = new THREE.ShaderMaterial({
    uniforms: {
      uColor: { value: new THREE.Color(style.color) },
      uStrength: { value: style.strength },
      uOpacity: { value: 1 },
      uReveal: { value: 1 },
      uOrigin: { value: O.clone() },
      uTime: { value: 0 }
    },
    vertexShader: FAN_VERTEX,
    fragmentShader: FAN_FRAGMENT,
    transparent: true,
    depthWrite: false,
    side: THREE.DoubleSide,
    blending: THREE.AdditiveBlending
  })
  const mesh = new THREE.Mesh(geometry, material)
  mesh.frustumCulled = false
  mesh.renderOrder = 2
  return { name, mesh, positions, material }
}

/** One triangle (pin, Pᵢ, Pᵢ₊₁) per step along the window's rim. */
const writeFan = (fan: ReturnType<typeof makeFan>, rim: Float32Array) => {
  for (let i = 0; i < FAN_TRIANGLES; i++) {
    const o = i * 9
    fan.positions[o] = O.x
    fan.positions[o + 1] = O.y
    fan.positions[o + 2] = O.z
    fan.positions.set(rim.subarray(i * 3, i * 3 + 6), o + 3)
  }
  fan.mesh.geometry.getAttribute('position').needsUpdate = true
}

export const createBow = (): SkyLayer => {
  const group = new THREE.Group()
  const color = new THREE.Color()
  let model: SkyModel | null = null
  let mode: BowMode = 'sky'
  let opacity = 1
  const reveal = { path: 1, horizon: 1, fans: WINDOW_NAMES.map(() => ({ value: 1 })) }

  // The path.
  const path = makeLine(PATH_SAMPLES, 2, null)
  path.line.renderOrder = 3
  group.add(path.line)

  // The fans, and a bright rim along each golden and blue one.
  const fans = WINDOW_NAMES.map(makeFan)
  for (const fan of fans) group.add(fan.mesh)
  const rims = fans
    .filter(fan => fan.name !== 'Daylight')
    .map((fan) => {
      const rim = makeLine(WINDOW_SAMPLES, 3, FAN_STYLE[fan.name].color)
      rim.line.renderOrder = 4
      group.add(rim.line)
      return { slot: WINDOW_NAMES.indexOf(fan.name), ...rim }
    })

  // The horizon: a glass disc, its ring, and a tick every 15°.
  const ringPoints = Array.from({ length: 129 }, (_, i) => {
    const a = (i / 128) * Math.PI * 2
    return new THREE.Vector3(O.x + R * Math.cos(a), O.y, O.z + R * Math.sin(a))
  })
  const ringMaterial = new THREE.LineBasicMaterial({ color: PALETTE.structure, transparent: true, depthWrite: false })
  const ring = new THREE.Line(new THREE.BufferGeometry().setFromPoints(ringPoints), ringMaterial)
  const tickPoints: THREE.Vector3[] = []
  for (let deg = 0; deg < 360; deg += 15) {
    const a = (deg * Math.PI) / 180
    const outer = deg % 90 === 0 ? 1.08 : 1.035
    tickPoints.push(
      new THREE.Vector3(O.x + R * Math.sin(a), O.y, O.z - R * Math.cos(a)),
      new THREE.Vector3(O.x + R * outer * Math.sin(a), O.y, O.z - R * outer * Math.cos(a))
    )
  }
  const tickMaterial = new THREE.LineBasicMaterial({ color: PALETTE.structure, transparent: true, depthWrite: false })
  const ticks = new THREE.LineSegments(new THREE.BufferGeometry().setFromPoints(tickPoints), tickMaterial)
  const discMaterial = new THREE.MeshBasicMaterial({
    color: PALETTE.structure,
    transparent: true,
    depthWrite: false,
    side: THREE.DoubleSide
  })
  const disc = new THREE.Mesh(new THREE.CircleGeometry(R, 96), discMaterial)
  disc.rotation.x = -Math.PI / 2
  disc.position.copy(O)
  for (const part of [ring, ticks, disc]) {
    part.renderOrder = 1
    group.add(part)
  }

  const glow = glowTexture()

    map: glow,
    color: PALETTE.pin,
    transparent: true,
    depthWrite: false,
    blending: THREE.AdditiveBlending

    transparent: true,
    depthWrite: false,
    side: THREE.DoubleSide,

  const stemMaterial = new THREE.LineBasicMaterial({ color: PALETTE.pin, transparent: true, depthWrite: false })
  const stem = new THREE.Line(
    new THREE.BufferGeometry().setFromPoints([O.clone(), O.clone().add(new THREE.Vector3(0, 0.07, 0))]),
    stemMaterial
  )
  stem.renderOrder = 6
  group.add(pin, pulse, stem)

  const pathColor = new Morph(PATH_SAMPLES * 3)
  const windowPosition = new Morph(WINDOW_NAMES.length * WINDOW_SAMPLES * 3)

  const write = () => {

      const rim = windowPosition.current.subarray(slot * WINDOW_SAMPLES * 3, (slot + 1) * WINDOW_SAMPLES * 3)
      writeFan(fan, rim)
    })
    for (const rim of rims) {
      writeLine(rim.geometry, windowPosition.current.subarray(rim.slot * WINDOW_SAMPLES * 3, (rim.slot + 1) * WINDOW_SAMPLES * 3))
    }
  }
  const runner = createMorphRunner([pathPosition, pathColor, windowPosition], write)

    if (!model) return
    const current = model
    const positions = new Float32Array(PATH_SAMPLES * 3)
    const colors = new Float32Array(PATH_SAMPLES * 3)
    current.path.forEach((s, i) => {

      color.set(KIND_COLORS[s.kind]).multiplyScalar(KIND_INTENSITY[s.kind] * visibilityOnBow(s.alt, mode))
      colors.set([color.r, color.g, color.b], i * 3)

        // A window this day does not have folds into the pin.
        const point = win ? layoutPoint(win.samples[i]!, mode, current.southern) : OBSERVER
        windows.set(point, (slot * WINDOW_SAMPLES + i) * 3)
      }
    })
    pathPosition.retarget(positions)
    pathColor.retarget(colors)
    windowPosition.retarget(windows)
    runner.run(duration)
  }

  return {
    object: group,
    setModel(next, duration) {
      model = next
      retarget(duration)
    },
    setMode(next, duration) {

      retarget(duration)
    },
    setSun() {},
    setOpacity(alpha) {
      opacity = alpha

    setResolution(width, height) {
      path.material.resolution.set(width, height)
      for (const rim of rims) rim.material.resolution.set(width, height)

    intro(timeline: gsap.core.Timeline) {
      reveal.path = 0
      reveal.horizon = 0

        .filter(entry => entry.win)
        .sort((a, b) => a.win!.start.getTime() - b.win!.start.getTime())
      reveal.fans.forEach((fan, slot) => {
        // A window this day does not have stays ready for a place that has one.
        fan.value = present.some(entry => entry.slot === slot) ? 0 : 1
      })
      timeline.to(reveal, { horizon: 1, duration: 0.8, ease: 'power1.out' }, 0.3)
      timeline.to(reveal, { path: 1, duration: 1.2, ease: 'power1.inOut' }, 0.4)
      present.forEach((entry, order) => {
        timeline.to(reveal.fans[entry.slot]!, { value: 1, duration: 0.7, ease: 'power2.out' }, 1.2 + order * 0.15)
      })
    },
    update(time) {
      path.geometry.instanceCount = Math.round(reveal.path * (PATH_SAMPLES - 1))
      path.material.opacity = opacity
      fans.forEach((fan, slot) => {
        const uniforms = fan.material.uniforms
        uniforms.uReveal!.value = reveal.fans[slot]!.value
        uniforms.uOpacity!.value = opacity
        uniforms.uTime!.value = time
      })
      for (const rim of rims) rim.material.opacity = opacity * reveal.fans[rim.slot]!.value
      ringMaterial.opacity = 0.35 * opacity * reveal.horizon
      tickMaterial.opacity = 0.3 * opacity * reveal.horizon
      discMaterial.opacity = 0.04 * opacity * reveal.horizon
      const beat = (time % 3) / 3
      pulse.scale.setScalar(1 + 3 * beat)
      pulseMaterial.opacity = 0.8 * (1 - beat) * opacity
      pinMaterial.opacity = opacity
      stemMaterial.opacity = 0.7 * opacity
    },
    dispose() {
      runner.kill()
      disposeTree(group)
      glow.dispose()
    }
  }
}
```

```ts
/**
 * The sun's strengths: a bead at every full hour, sized and lit by how high
 * the sun stands then, and the sun itself at now or at solar noon
 * (spec 5.4, 5.5 and 7.5).
 */
import * as THREE from 'three'
import type gsap from 'gsap'
import { OBSERVER, layoutPoint, visibilityOnBow, type BowMode, type SkyModel, type SkySample } from '../skyGeometry'
import { disposeTree } from './dispose'
import { Morph, createMorphRunner } from './morph'
import { beadColor, sunColor } from './palette'
import { glowTexture, raysTexture, ringTexture } from './textures'
import type { SkyLayer } from './types'

/** Room for every full hour of a span, with a spare. */
const BEAD_SLOTS = 26

const BEAD_VERTEX = /* glsl */ `
  attribute vec3 aColor;
  attribute float aSize;
  attribute float aF;
  uniform float uPixelRatio;
  uniform float uReveal;
  uniform float uOpacity;
  varying vec3 vColor;
  varying float vAlpha;
  void main() {
    vec4 mv = modelViewMatrix * vec4(position, 1.0);
    // The opening lights the beads in time order.
    float shown = smoothstep(aF - 0.03, aF + 0.03, uReveal);
    vColor = aColor;
    vAlpha = shown * uOpacity;
    gl_PointSize = aSize * uPixelRatio * shown * clamp(3.2 / -mv.z, 0.55, 1.4);
    gl_Position = projectionMatrix * mv;
  }`

const BEAD_FRAGMENT = /* glsl */ `
  varying vec3 vColor;
  varying float vAlpha;
  void main() {
    float d = length(gl_PointCoord - 0.5);
    if (d > 0.5) discard;
    float core = smoothstep(0.18, 0.0, d);
    float glow = pow(smoothstep(0.5, 0.0, d), 2.0);
    gl_FragColor = vec4(vColor, (core * 0.9 + glow * 0.6) * vAlpha);
    #include <colorspace_fragment>
  }`

export const createBeads = (): SkyLayer => {
  const group = new THREE.Group()
  const color = new THREE.Color()
  let model: SkyModel | null = null
  let mode: BowMode = 'sky'
  let sample: SkySample | null = null
  let opacity = 1
  let sunVisible = 1
  const reveal = { beads: 1, sun: 1 }

  // The beads.
  const attribute = (size: number) =>
    new THREE.BufferAttribute(new Float32Array(BEAD_SLOTS * size), size).setUsage(THREE.DynamicDrawUsage)
  const positionAttribute = attribute(3)
  const colorAttribute = attribute(3)
  const sizeAttribute = attribute(1)
  const shareAttribute = attribute(1)
  const geometry = new THREE.BufferGeometry()
  geometry.setAttribute('position', positionAttribute)
  geometry.setAttribute('aColor', colorAttribute)
  geometry.setAttribute('aSize', sizeAttribute)
  geometry.setAttribute('aF', shareAttribute)
  const material = new THREE.ShaderMaterial({
    uniforms: { uPixelRatio: { value: 1 }, uReveal: { value: 2 }, uOpacity: { value: 1 } },
    vertexShader: BEAD_VERTEX,
    fragmentShader: BEAD_FRAGMENT,
    transparent: true,
    depthWrite: false,
    blending: THREE.AdditiveBlending
  })
  const beads = new THREE.Points(geometry, material)
  beads.frustumCulled = false
  beads.renderOrder = 5
  group.add(beads)

  // The sun: a core, a breathing halo, slow rays, and a ring for when it is down.
  const glow = glowTexture()
  const rays = raysTexture()
  const ring = ringTexture()
  const sprite = (map: THREE.Texture, size: number) => {
    const s = new THREE.Sprite(
      new THREE.SpriteMaterial({ map, transparent: true, depthWrite: false, blending: THREE.AdditiveBlending })
    )
    s.scale.setScalar(size)
    s.renderOrder = 6
    return s
  }
  const halo = sprite(glow, 0.9)
  const sunRays = sprite(rays, 1.15)
  const core = sprite(glow, 0.22)
  const marker = sprite(ring, 0.14)
  const sun = new THREE.Group()
  sun.add(halo, sunRays, core, marker)
  group.add(sun)

  // Everything that glides.
  const beadPosition = new Morph(BEAD_SLOTS * 3)
  const beadTint = new Morph(BEAD_SLOTS * 3)
  const beadSize = new Morph(BEAD_SLOTS)
  const sunPosition = new Morph(3)
  /** r, g, b, and how visible the sun is (1 up, 0 down on the sky path). */
  const sunState = new Morph(4)

  const write = () => {
    ;(positionAttribute.array as Float32Array).set(beadPosition.current)
    ;(colorAttribute.array as Float32Array).set(beadTint.current)
    ;(sizeAttribute.array as Float32Array).set(beadSize.current)
    positionAttribute.needsUpdate = true
    colorAttribute.needsUpdate = true
    sizeAttribute.needsUpdate = true
    sun.position.fromArray(sunPosition.current)
    const [r, g, b, visible] = sunState.current
    for (const s of [halo, sunRays, core]) s.material.color.setRGB(r!, g!, b!)
    sunVisible = visible!
  }
  const runner = createMorphRunner([beadPosition, beadTint, beadSize, sunPosition, sunState], write)

  const sunTargets = () => {
    if (!model || !sample) return null
    sunColor(sample.alt, color)
    const visible = mode === 'clock' ? 1 : THREE.MathUtils.smoothstep(sample.alt, -1.5, 1)
    return { position: layoutPoint(sample, mode, model.southern), state: [color.r, color.g, color.b, visible] }
  }

  const retarget = (duration: number) => {
    if (!model) return
    const current = model
    const positions = new Float32Array(BEAD_SLOTS * 3)
    const tints = new Float32Array(BEAD_SLOTS * 3)
    const sizes = new Float32Array(BEAD_SLOTS)
    const shares = shareAttribute.array as Float32Array
    for (let i = 0; i < BEAD_SLOTS; i++) {
      const bead = current.beads[i]
      if (!bead) {
        // An empty slot: no size, never revealed.
        positions.set(OBSERVER, i * 3)
        shares[i] = 2
        continue
      }
      positions.set(layoutPoint(bead, mode, current.southern), i * 3)
      beadColor(bead, color).multiplyScalar(visibilityOnBow(bead.alt, mode))
      tints.set([color.r, color.g, color.b], i * 3)
      sizes[i] = bead.kind === 'night' ? 6 : 9 + 9 * bead.strength
      shares[i] = bead.f
    }
    shareAttribute.needsUpdate = true
    beadPosition.retarget(positions)
    beadTint.retarget(tints)

    object: group,
    setModel(next, duration) {

    setMode(next, duration) {

      retarget(duration)

      const target = sunTargets()
      if (!target) return
      sunPosition.retarget(target.position)
      sunState.retarget(target.state)
      // Mid-glide the running morph carries the sun along; otherwise it steps.
      if (!runner.running) {
        sunPosition.apply(1)
        sunState.apply(1)
        write()

    setOpacity(alpha) {

    setResolution(_width, _height, pixelRatio) {
```

```ts
/**
 * The words on the stage: each golden and blue window's times at the tip of
 * its fan, and the compass letters on the horizon ring. HTML drawn by
 * CSS2DRenderer, so they use the app's own type roles (spec 7.5).
 */
import * as THREE from 'three'
import { CSS2DObject } from 'three/addons/renderers/CSS2DRenderer.js'
import type gsap from 'gsap'
import type { Vec3 } from '../globeMath'
import {
  BOW_RADIUS,
  OBSERVER,
  WINDOW_SAMPLES,
  layoutPoint,
  type BowMode,
  type SkyModel,
  type SkySample,
  type WindowName
} from '../skyGeometry'
import { Morph, createMorphRunner } from './morph'
import { PALETTE } from './palette'
import type { SkyLayer } from './types'

const R = BOW_RADIUS
const LABELLED: WindowName[] = ['Morning Blue Hour', 'Morning Golden Hour', 'Evening Golden Hour', 'Evening Blue Hour']
const MIDDLE = Math.floor(WINDOW_SAMPLES / 2)
/** Legible over a bright planet as well as over space. */
const SHADOW = '0 0 6px rgba(0,0,0,0.95), 0 0 14px rgba(0,0,0,0.8)'

const formatTime = (d: Date) =>
  d.toLocaleTimeString(undefined, { hour: '2-digit', minute: '2-digit', hour12: false })

export const createLabels = (): SkyLayer => {
  const group = new THREE.Group()
  let model: SkyModel | null = null
  let mode: BowMode = 'sky'
  let opacity = 1
  let settled = true
  const reveal = { labels: 1 }

  const windows = LABELLED.map((name) => {
    const golden = name.includes('Golden')
    const element = document.createElement('div')
    element.className = 't-num-xs whitespace-nowrap'
    element.style.color = golden ? PALETTE.golden : PALETTE.blue
    element.style.textShadow = SHADOW
    element.style.transition = 'opacity 0.3s ease'
    const object = new CSS2DObject(element)
    group.add(object)
    return { name, golden, element, object, text: '' }
  })

  const compass = (['N', 'E', 'S', 'W'] as const).map((letter, i) => {
    const element = document.createElement('div')
    element.className = 't-label-xs'
    element.textContent = letter
    element.style.textShadow = SHADOW
    const angle = (i * Math.PI) / 2
    const object = new CSS2DObject(element)
    object.position.set(OBSERVER[0] + Math.sin(angle) * R * 1.16, OBSERVER[1], OBSERVER[2] - Math.cos(angle) * R * 1.16)
    group.add(object)
    return element
  })

  /** Outside the rim: golden above and blue below on the sky path, stacked outward on the clock. */
  const anchorFor = (middle: SkySample, golden: boolean, southern: boolean): Vec3 => {
    if (mode === 'sky') {
      const [x, y, z] = layoutPoint(middle, 'sky', southern, R * 1.14)
      return [x, y + (golden ? 0.07 : -0.07), z]
    }
    return layoutPoint(middle, 'clock', southern, R * (golden ? 1.12 : 1.26))
  }

  const anchors = new Morph(LABELLED.length * 3)
  const write = () => {
    windows.forEach((label, i) => label.object.position.fromArray(anchors.current, i * 3))
  }
  const runner = createMorphRunner([anchors], write)
  const showTexts = () => {
    for (const label of windows) label.element.textContent = label.text
  }

  const retarget = (duration: number) => {
    if (!model) return
    const current = model
    const targets = new Float32Array(LABELLED.length * 3)
    windows.forEach((label, i) => {
      const win = current.windows.find(w => w.name === label.name)
      label.object.visible = !!win
      label.text = win ? `${formatTime(win.start)}–${formatTime(win.end)}` : ''
      targets.set(win ? anchorFor(win.samples[MIDDLE]!, label.golden, current.southern) : OBSERVER, i * 3)
    })
    anchors.retarget(targets)
    if (duration > 0) {
      // Fade out while gliding; the new times appear when the labels land.
      settled = false
      runner.run(duration, () => {
        showTexts()
        settled = true
      })
    } else {
      runner.run(0)
      showTexts()
      settled = true
    }
  }

  let lastWindowOpacity = -1
  let lastCompassOpacity = -1

  return {
    object: group,
    setModel(next, duration) {
      model = next
      retarget(duration)
    },
    setMode(next, duration) {
      mode = next
      retarget(duration)
    },
    setSun() {},
    setOpacity(alpha) {
      opacity = alpha
    },
    setResolution() {},
    intro(timeline: gsap.core.Timeline) {
      reveal.labels = 0
      timeline.to(reveal, { labels: 1, duration: 0.4, ease: 'power1.out' }, 2.1)
    },
    update() {
      const windowOpacity = settled ? opacity * reveal.labels : 0
      if (windowOpacity !== lastWindowOpacity) {
        for (const label of windows) label.element.style.opacity = String(windowOpacity)
        lastWindowOpacity = windowOpacity
      }
      const compassOpacity = opacity * reveal.labels * 0.85
      if (compassOpacity !== lastCompassOpacity) {
        for (const element of compass) element.style.opacity = String(compassOpacity)
        lastCompassOpacity = compassOpacity
      }
    },
    dispose() {
      runner.kill()
      group.clear()
    }
  }
}
```

```markdown
The orbit button in the Day Schedule header opens a full-screen 3D view of the

*   **There is no time scrubber, on purpose.** On one place the fans already
```
